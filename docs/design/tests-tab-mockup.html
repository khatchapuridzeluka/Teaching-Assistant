class StudentAccount implements Account {
    private final Wallet w = new Wallet();
    public void deposit(int a)  { w.addMoney(a); }
    public void withdraw(int a) { w.takeMoney(a); }
    public int balance()        { return w.getBalance(); }
    public void transferTo(Account o, int a) {
        throw new NotImplemented("no transfer method");
    }
}
These results go to the grader with the code, so the review can say "withdraw allows a negative balance (T4)" with evidence.
